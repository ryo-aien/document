# .claude ディレクトリ構成

## 概要

`.claude`ディレクトリは、Claude Codeがローカルに作業履歴、設定、キャッシュデータを保存するための専用ディレクトリです。このディレクトリにより、プロジェクト間での設定管理、作業履歴の追跡、効率的なキャッシュ活用が可能になります。

**2つのレベルが存在：**
- **ホームディレクトリ**: `~/.claude/` - システム全体の設定と状態
- **プロジェクトディレクトリ**: `<project>/.claude/` - プロジェクト固有の設定

## ホームディレクトリ構成（`~/.claude/`）

| 項目名 | 種類 | カテゴリ | 説明 |
|--------|------|----------|------|
| `cache/` | ディレクトリ | データストレージ | API応答やその他の一時データのキャッシュを保存 |
| `plugins/` | ディレクトリ | 拡張機能 | プラグインファイルとマーケットプレイスの設定を保存 |
| `projects/` | ディレクトリ | プロジェクト管理 | プロジェクトごとの設定やデータ（許可されたツール、信頼設定など） |
| `file-history/` | ディレクトリ | 履歴・記録 | ファイル変更履歴の追跡データを保存 |
| `debug/` | ディレクトリ | トラブルシューティング | デバッグ情報やエラーログを保存 |
| `shell-snapshots/` | ディレクトリ | 履歴・記録 | シェル状態のスナップショットを保存 |
| `plans/` | ディレクトリ | タスク管理 | AIが生成したタスクプランを保存 |
| `todos/` | ディレクトリ | タスク管理 | タスク管理データやToDoリストを保存 |
| `statsig/` | ディレクトリ | 統計・分析 | 統計・分析データ（Statsig機能フラグ管理） |
| `profiles/`※ | ディレクトリ | 設定 | タスク別の設定プロファイル（セキュリティ監査、リファクタリングなど） |
| `settings.json` | ファイル | 設定 | グローバル設定（パーミッション、環境変数、hooks等） |
| `session-env` | ファイル | 設定 | セッション環境変数を保存 |
| `history.jsonl` | ファイル | 履歴・記録 | コマンド実行履歴（JSONL形式） |
| `stats-cache.json` | ファイル | 統計・分析 | 統計情報のキャッシュ |
| `CLAUDE.md`※ | ファイル | メモリ | グローバルに適用されるプロジェクト指示・設定 |

※ユーザーが任意で作成可能な項目

## プロジェクトディレクトリ構成（`<project>/.claude/`）

| 項目名 | 種類 | 説明 |
|--------|------|------|
| `CLAUDE.md` | ファイル | プロジェクト固有の指示・コーディング規約・ワークフロー |
| `settings.json` | ファイル | プロジェクト固有の設定（hooks, permissions等） |
| `settings.local.json` | ファイル | 個人用設定（.gitignore推奨） |
| `skills/` | ディレクトリ | カスタムスキルファイル（SKILL.md） |
| `commands/` | ディレクトリ | カスタムスラッシュコマンド |
| `agents/` | ディレクトリ | サブエージェント定義 |


### 初期設定のヒント
1. プロジェクトディレクトリで`/init`コマンドを実行してCLAUDE.mdを自動生成
2. 生成されたCLAUDE.mdをレビューし、チーム固有の規約を追加
3. `.gitignore`に`settings.local.json`を追加
4. プロジェクトの`.claude/settings.json`でhooksを設定し、品質ゲートを自動化
