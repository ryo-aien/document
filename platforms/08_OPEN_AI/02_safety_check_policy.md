## 安全チェック
| 名前           | 形容                                                                                                                                         |
|----------------|----------------------------------------------------------------------------------------------------------------------------------------------|
| 助言           | 当社のポリシーに違反するアドバイスまたはガイダンス。                                                                                          |
| 嫌がらせ/脅迫  | ターゲットに対する暴力や重大な危害も含む嫌がらせコンテンツ。                                                                                  |
| 憎む           | 人種、性別、民族、宗教、国籍、性的指向、障害の有無、カーストに基づく憎悪を表現、扇動、または助長するコンテンツ。保護されていないグループ(チェスプレイヤーなど)を対象としたヘイトコンテンツは嫌がらせです。 |
| 憎悪/脅迫      | 人種、性別、民族、宗教、国籍、性的指向、障害の有無、カーストに基づく対象グループに対する暴力や重大な危害を含むヘイトコンテンツ。               |
| 高感度         | ポリシーに違反する機密性の高いデータ。                                                                                                      |
| 違法           | 違法行為の方法についてアドバイスや指示を与えるコンテンツ。「万引きの方法」のようなフレーズは、このカテゴリに当てはまります。                    |
| プロパガンダ   | 私たちのポリシーに違反するイデオロギーを賞賛または支援します。                                                                               |
| 自傷行為/指示  | 自殺、切断、摂食障害などの自傷行為を助長するコンテンツ、またはそのような行為を行う方法について指示やアドバイスを提供するコンテンツ。            |
| 自傷行為/意図  | 話者が自殺、切断、摂食障害などの自傷行為に関与している、または関与するつもりであることを表明するコンテンツ。                                    |
| 敏感           | ポリシーに違反する機密データ。                                                                                                              |
| セクシュアル/未成年者 | 18 歳未満の個人を含む性的なコンテンツ。                                                                                                  |
| 性的           | 性行為の説明など、性的興奮を誘発することを目的としたコンテンツ、または性的サービス(性教育や健康を除く)を促進するコンテンツ。                    |
| 暴力           | 死亡、暴力、身体的傷害を描写するコンテンツ。                                                                                                 |
