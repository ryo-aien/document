## ・「月額固定」と「従量課金」のどちらが良いか

### 使い分け

| 利用パターン                       | 推奨課金方式      | 理由                         |
| ---------------------------- | ----------- | ---------------------------- |
| 毎日長時間使う（常時稼働）            | 月額固定        | 時間単価が下がり、コスト安定          |
| 不定期に使う（検証・週数回）           | 従量課金        | 利用分だけ支払い                 |
| スポットで一気に学習               | 従量課金 + Spot | 一時的な利用に向く                |
| クラウドを常時ホスト用途に使う（API稼働など） | 月額固定        | 常時起動なら固定                 |

### 判断基準

| 判断項目         | 固定課金が有利              | 従量課金が有利              |
| ---------------- | --------------------------- | --------------------------- |
| 月間利用時間     | 100時間以上                  | 100時間未満                  |
| 利用頻度         | 毎日 or 平日フル稼働         | 数回/週 程度の軽い使用         |
| 用途             | 商用/ホスティング/APIなどの常時運用 | 実験/学習/研究などの一時的用途     |
| 予算の見通し     | 固定で安心・見積もりしやすい       | 使った分だけ請求             |
| 停止自動化スキル | 不要（常時稼働前提）           | 必須（shutdown忘れで高額課金も） |
| スケーラビリティ | 台数固定・運用最適化           | 必要に応じてノードを柔軟に起動      |

| 会社の状況・用途例             | おすすめ課金形式              |
| ----------------------------- | ----------------------------- |
| 社内チャットボットAPIを常時稼働     | 月額固定（RunPod / Lambda） |
