# 日本語形態素解析

## 形態素解析とは？

日本語の文章は、英語のように単語の間にスペースがありません。  
そのため、機械にとっては「どこからどこまでが単語なのか」が分かりにくくなっています。

**形態素解析**とは、文章を「意味のある最小単位（形態素）」に分割し、  
それぞれに品詞などの情報を付ける処理のことです。

例：
```

入力：  推し活を始めました
出力：  推し活（名詞） / を（助詞） / 始める（動詞） / ました（助動詞）

```

## 解析結果の違いがわかる例

### 例1：流行語

```

推し活を始めました

```

| ツール         | 分割結果                          |
|----------------|----------------------------------|
| MeCab（IPA辞書） | 推し / 活 / を / 始め / まし / た    |
| MeCab + NEologd | 推し活 / を / 始め / まし / た       |
| SudachiPy       | 推し活 / を / 始める / ます / た     |

→ NEologdやSudachiは「推し活」を**1語で認識**するので意味が明確。

---

### 例2：専門用語（IT系）

```

LLMをRAG構成で社内FAQに使いたい

```

| ツール         | 分割結果例                               |
|----------------|------------------------------------------|
| MeCab（IPA）   | LLM / を / RAG / 構成 / で / 社内 / FAQ ... |
| NEologd        | LLM / を / RAG構成 / で / 社内FAQ / ...     |
| SudachiPy      | LLM / RAG構成 / 社内FAQ / に / 使いたい     |

→ 専門語を複合語として認識できるツールの方が、**正確な理解や分類に強い**。

## ツールごとの特徴まとめ

### ・ MeCab
- 高速・安定
- 古くから使われていて実績あり
- ただし辞書によって語彙力に差が出やすい

### ・ NEologd（MeCab用辞書）
- ネット・SNS・新語に非常に強い
- 固有名詞・カジュアルな文で効果大
- インストールにやや手間がかかる

### ・ SudachiPy
- 複合語（例：社内FAQ）を1単語として認識
- 表記ゆれや記号処理にも対応
- Pythonから簡単に使える

### ・ GiNZA
- SudachiPyベースの高機能パイプライン
- 固有表現抽出（人名、組織名など）や構文解析（係り受け）も可能
