## *タスク特化型モデルの一覧*
| タスク         | 主なモデル例                           | 特徴               | 代表的な利用ケース            |
| ----------- | -------------------------------- | ---------------- | -------------------- |
| テキスト分類      | BERT, RoBERTa                    | 高精度な文脈理解         | メール振り分け、ニュースカテゴリ分類   |
| 固有表現抽出（NER） | BERT+CRF, Flair                  | 文中の固有名詞を高精度で抽出   | 契約書や論文のキーワード抽出       |
| 感情分析        | BERT系, TextCNN                   | SNSやレビューのポジネガ分析  | 商品レビュー評価、SNS監視       |
| 機械翻訳        | Transformer, MarianMT            | 高速で高精度な多言語翻訳     | Webサイト多言語化           |
| 要約          | BART, PEGASUS, T5                | 長文をコンパクトに要約      | ニュース要約、議事録要約         |
| 質問応答        | BERT QA, RoBERTa QA              | コンテキストに基づく直接回答   | FAQチャットボット、ドキュメント検索  |
| 自然言語生成      | GPT-2, GPT-3, LLaMA              | 高品質な文章生成         | チャットAI、文章自動作成        |
| 文書類似度評価     | Sentence-BERT, SimCSE            | 意味ベースの文類似度計算     | FAQマッチング、検索ランキング     |
| 音声認識（テキスト化） | Whisper, Wav2Vec2                | ノイズ環境でも強い性能      | 音声メモの文字起こし、字幕生成      |
| 文書分類（多ラベル）  | XML-CNN, HAN                     | 1文書に複数タグを付与可能    | ニュースや論文の複数トピック分類     |
| 構文解析        | SyntaxBERT                       | 文法構造の理解          | 機械翻訳や文法訂正の前処理        |
| 多言語タスク      | XLM-R, mBERT                     | 多言語対応モデル         | グローバル展開アプリの言語理解      |
| スペル訂正       | BERT（seq2seq）                    | 文脈に沿った訂正         | チャットや入力補正            |
| RAG（検索拡張生成） | DPR + BART, BM25 + T5            | 外部知識検索と生成を組み合わせ  | ドキュメントQ\&A、ナレッジベース検索 |
| 画像分類        | ResNet, EfficientNet, ViT        | 精度・速度・サイズでバランス可能 | 医療画像診断、動物・植物分類       |
| 物体検出        | YOLO, Faster R-CNN, DETR         | 高速または高精度な物体位置検出  | 監視カメラ、ロボット視覚         |
| セグメンテーション   | U-Net, DeepLab, Mask R-CNN       | ピクセル単位で領域分割      | 自動運転、医療診断            |
| ポーズ推定       | OpenPose, HRNet                  | 人体の関節位置検出        | AR/VR、スポーツ分析         |
| 顔認識         | ArcFace, FaceNet                 | 高精度な顔の特徴抽出       | 顔認証ログイン、写真整理         |
| 画像生成        | GAN, StyleGAN2, Stable Diffusion | 高解像度で多様な画像生成     | 広告ビジュアル作成、キャラクターデザイン |
| 超解像         | ESRGAN, EDSR                     | 低解像度画像を高精細化      | 古い映像の高画質化、衛星画像解析     |
| 画像キャプショニング  | Show and Tell, OFA               | 画像内容をテキストで説明     | 視覚障害者支援、商品説明生成       |
| 行動認識（動画）    | I3D, SlowFast                    | 動画内の行動や動作を認識     | スポーツプレイ解析、防犯映像解析     |
| 3Dオブジェクト認識  | PointNet, PointNet++             | 点群データで3D物体を認識    | 自動運転のLIDAR処理、ロボット工学  |
| 音声認識        | DeepSpeech, Wav2Vec2, Whisper    | 音声を正確にテキスト化      | 会議録音の文字起こし           |
| 音声合成（TTS）   | Tacotron2, FastSpeech, VITS      | 自然な音声を合成         | 音声アシスタント、読み上げソフト     |
| 声質変換        | StarGAN-VC, MelGAN               | 声の個性を保ちつつ別の声に変換  | VTuber、ボイスチェンジャー     |
| 音声感情認識      | CNN-LSTM, wav2vec2+MLP           | 声から感情を推定         | コールセンター分析、ゲームAI      |
| 強化学習        | DQN, PPO, SAC, A3C               | 状況に応じた行動最適化      | ゲームAI、自律ロボット         |
| 時系列予測       | LSTM, Informer, N-BEATS, TFT     | 長期依存を捉えた予測       | 需要予測、株価予測            |
| 推薦システム      | Wide & Deep, DeepFM, DIN         | 行動履歴や特徴を考慮して推薦   | ECサイトの商品レコメンド        |
| 異常検知        | Isolation Forest, AutoEncoder    | 正常データとの差分で異常を検知  | システム監視、製造ライン検品       |
| OCR（文字認識）   | CRNN, TrOCR                      | 画像内の文字列を抽出       | 紙文書デジタル化、レシート読取      |
